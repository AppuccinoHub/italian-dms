# Italian DMs

Italian DMs is an installable classroom PWA for practicing **essere** and **avere** (Level 2).

## For teachers

- This is the installable PWA. Open the GitHub Pages URL in a browser.
- On Chromebooks, open the Pages URL directly.
- On iPhone, open the Pages URL in Safari, tap **Share**, then **Add to Home Screen**.
- Do **not** open `index.html` as a downloaded HTML file; the app and offline installation require the Pages URL.
